# Days 08 and 09 — data, modelling and reproducibility

These maps are not AI-generated images. The figures and raster maps are generated by
[maps/day08_day09.py](../../maps/day08_day09.py), with automated tests. All
precomputed outputs are committed to the repository to prevent unreliable live
raster requests in visitors' browsers.

Run the build again using Python 3.12 and the project's test dependencies:

\`\`\`bash
python -m pip install -e '.[test]'
python -m maps.day08_day09
python -m pytest tests/test_day08_day09.py
node --test tests/day08-day09.test.cjs
\`\`\`

The separate GitHub Actions workflow
[Build real data for Days 8 and 9](../../.github/workflows/build-day08-day09.yml)
runs this build in CI on the source feature branch and commits the resulting
assets. The input datasets remain publicly traceable.

## Day 08 — North East, 2050: A Land Reclaimed

**Measured source layers**

- ESA WorldCover 2021 v200, a 10 m satellite land-cover classification; the
  region-wide modelling grid samples it at 300 m by nearest neighbour.
- ONS Regions December 2025 boundary, specifically E12000001, including Tees Valley.
- OpenStreetMap source ways for named Tyne, Wear and Tees river segments and ways
  tagged abandoned or disused railway, retrieved via Overpass. OSM records are
  not proof that a railway is usable as a path, nor do mapped waterways imply
  feasible floodplain restoration.

**Explicitly hypothetical future**

50% of the *classified terrestrial samples in the official North East study
region* are allocated to a nature-first scenario. The model starts with source
cells labelled as tree cover or wetland; it does not claim these areas are
ecologically intact. The allocation adds cells while excluding built-up land,
using a score favouring:

1. Westward location (a conceptual upland-oriented core).
2. Proximity to source tree/wetland samples.
3. Within 450 m of named river centreline ways.
4. Within 160 m of abandoned/disused railway ways.
5. A small preference for grassland relative to cropland.

The score is **a designed editorial scenario**, not a quantified habitat
suitability model. Targeting 50% is a creative constraint, not a policy forecast.
It ignores ownership, cost, consent, soil, biodiversity priorities, food
production, legal access, flood risk and urban planning. In particular, neither
ecological connectivity nor public access is measured. The model does not
claim that today's woods and wetlands are 16.6% of the *actual area* to survey
grade precision, because the base is a 300 m sampled classification.

Generated files:

- web/day08-utopia/data/today.png
- web/day08-utopia/data/2050.png
- web/day08-utopia/data/metrics.json

## Day 09 — Where does the city end?

**Entirely measured, not speculative**

- Same ESA WorldCover 2021 source (10 m).
- A straight line between Newcastle city centre (54.9783, -1.6178) and
  Hamsterley Forest (54.675, -1.859), projected in British National Grid.
- 85 regularly spaced measured sampling locations.
- Each local composition represents classified pixels sampled at 40 m
  resolution, falling within an approximately 500 m radius.
- Built-up = class 50; trees = 10; cropland = 40; grass/shrub = 20+30;
  other = valid remaining WorldCover classes.
- Percentage series are derived solely from the stored classification values,
  not hand-written, not AI-generated, and not smoothed.
- The map image is a strip of actual classified pixels, rotated to present
  the transect as a horizontal journey. It is not a route people can follow.

Generated files:

- web/day09-urban-rural/data/transect.png
- web/day09-urban-rural/data/profile.json

**Limits:** this is a land-cover composition along a chosen transect and
reflects classifications from 2021, not a binary urban/rural designation,
human population, public accessibility or 2026 land-cover change. Raster source
classification and resampling introduce uncertainty. A 500 m radius includes
places to either side of the straight line.
